Проведи релиз линейки «Навар» строго по шагам. Любой красный шаг — стоп, чинить, начинать заново с шага 1.

1. **Конвейер.** Запусти `node runner.js` в корне проекта. Если не «КОНВЕЙЕР ЗЕЛЁНЫЙ» — чини код (эталоны неприкосновенны) и запусти заново. Дальше не идти, пока не зелёный.
2. **Версия и дата.** В футерах navar.html и navar-auto.html подними версию (vX.Y — минор при правках формул/фич, патч при текстах/стилях) и поставь текущие месяц и год в «формулы сверены: месяц год». Если файлы собираются из шаблона — правь шаблон и пересобери, руками собранные файлы не трогай.
3. **Повторный конвейер.** Ещё раз `node runner.js` — правка футера не должна ничего сломать.
4. **Коммит.** `git add` изменённых файлов, коммит с сообщением вида `release: vX.Y — краткое описание изменений`.
5. **Деплой.** Если настроен GitHub Pages — `git push`. Проверь живые URL (открой в браузере, сверь версию в футере). Если Pages ещё нет — сообщи, что деплой пропущен.
6. **Отчёт.** Короткий итог: версия, что вошло, ссылки.
