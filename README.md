# Навар — честные калькуляторы для тех, кто продаёт

Линейка автономных калькуляторов юнит-экономики для русскоязычных продавцов.
Каждый продукт — **один самодостаточный HTML-файл**: работает офлайн, с `file://`,
без сервера, без регистраций. **Данные не покидают браузер** — никакой аналитики
и запросов наружу.

## Что считают

**Навар · Авито** — честный навар с одной продажи: комиссия с минимальным
удержанием (на дешёвом товаре «6%» превращаются в 12%+), доля продаж через
Авито Доставку, невыкупы с обратной доставкой, ДРР и платные размещения,
налог (УСН 6% / УСН 15% / НПД с предупреждением, что перепродажа под НПД
не подпадает). Плюс безубыточность, целевая маржа и итог за месяц.

**Навар.Авто** — сделка перекупа до того, как отданы деньги: навар со сделки
и **навар в день** (машина, висящая 60 дней, кормит хуже двух быстрых обменов),
**потолок торга** на осмотре под желаемый заработок, стоимость кредитных денег,
стресс-тест «зависла» (+30 дней, скидка, доремонт), годовой темп и НДФЛ по
документам.

Обе считалки: сохранение вариантов в сравнительную таблицу, «Ссылка на расчёт»
(всё состояние в URL через lz-string), PNG-карточка для чата, экспорт/импорт JSON.

## Принципы (нарушать нельзя)

1. Один самодостаточный HTML-файл на продукт. Без CDN — библиотеки вендорятся
   внутрь (lz-string, MIT).
2. Данные не покидают браузер. Персистентность — URL-hash и экспорт/импорт JSON.
   localStorage не используется.
3. Вся математика — через единые функции (`netAt`/`calc` для формы, `computeItem`
   для таблицы). Импорт и hash **пересчитывают** метрики: хранимым цифрам не доверяем.
4. Честность выше красоты: предупреждения и оговорки не удаляются и не смягчаются.
5. Релиз только через зелёный конвейер + версия и дата в футере.

## Устройство репозитория

```
template/               исходники: правки делаются ТОЛЬКО здесь
  navar.tpl.html        шаблон Навар · Авито
  navar-auto.tpl.html   шаблон Навар.Авто
  shared/*.inc          общие байт-в-байт блоки (lz-string, таблица, hash, стили)
build.js                сборка: шаблоны + блоки -> navar.html, navar-auto.html
                        + копии для Pages в navar/ и avto/
runner.js, test*.js     тестовый конвейер (jsdom), эталоны посчитаны вручную
index.html              лендинг
launch/                 материалы запуска (посевы, Telegram, кнопка PRO)
```

`navar.html` и `navar-auto.html` — **артефакты сборки**, руками не редактировать.

## Разработка

```bash
npm install        # один раз (jsdom)
# правим template/...
npm run build      # собрать продукты
npm run check      # конвейер: 8 наборов тестов
```

Правила конвейера: упал тест → чинить код, эталоны неприкосновенны (намеренная
смена поведения — эталон обновляется с ручным пересчётом в комментарии).
Дебаунс записи hash 800 мс — лимит Safari на `replaceState`, не уменьшать.

## Честность

Расчёты справочные. Налоговые блоки упрощены и не являются налоговой или
юридической консультацией — крайние случаи сверяйте с налоговой. Точные ставки
комиссий смотрите в своём кабинете Авито и вписывайте в калькулятор.
