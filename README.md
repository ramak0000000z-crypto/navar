# Конвейер «Навар» — автоматическая проверка перед каждым релизом

Положи navar.html и navar-auto.html в эту папку. Затем один раз: `npm install`.

Дальше цикл всегда одинаковый:
1. Правишь HTML-файлы (сам или со мной).
2. `npm run check` — 79 проверок: эталонные расчёты, налоги, крайние случаи, XSS, импорт с подделанными данными, все фишки.
3. Зелёно → поднимаешь версию в футере (vX.Y · сверено: месяц год) → выкладываешь.
4. Красно → в выводе видно, какой именно расчёт разошёлся с эталоном.

Эталоны в тестах посчитаны вручную и независимо от кода — если тест упал, врёт код, а не тест.
