# Кнопка «199 ₽/мес» — замер спроса без сбора данных

## Принцип

Никаких форм, бэкенда и сбора контактов — это нарушило бы «данные не покидают
браузер». Кнопка ведёт в Telegram: клик и подписка/сообщение = сигнал спроса.
Контакт человек оставляет сам, на своей территории. Ничего не продаём: честная
плашка «в разработке».

## Что обещает PRO (гипотеза для проверки спроса)

Сохранение товаров/сделок между сессиями, сравнение периодов, экспорт в таблицу,
уведомления об изменении тарифов Авито. НЕ обещать сроков.

## Сниппет для template/*.tpl.html (вставить перед footer, когда будет адрес канала)

```html
<div class="panel" style="max-width:1140px;margin:0 auto 22px;padding:18px 24px;display:flex;gap:14px;align-items:center;flex-wrap:wrap">
  <div style="flex:1;min-width:220px">
    <b>Навар PRO — 199 ₽/мес</b>
    <div style="font-size:13px;opacity:.75">Сохранение между сессиями, сравнение периодов, экспорт в таблицу. В разработке — узнай первым и повлияй на список фич.</div>
  </div>
  <a class="btn" href="https://t.me/{КАНАЛ}?start=pro" target="_blank" rel="noopener">Хочу PRO → Telegram</a>
</div>
```

Порядок включения: создать канал → вписать адрес вместо {КАНАЛ} → вставить блок
в оба шаблона (или в общий .inc) → `node build.js` → конвейер → /release.

## Как мерить

Телеграм покажет подписки/сообщения после посева. Если за 2–3 недели посевов
сигналов меньше ~20 — гипотезу 199 ₽/мес пересматривать, а не дожимать.
